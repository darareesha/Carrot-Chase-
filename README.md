# Carrot Chase (2D Infinite Runner Game)
Carrot Chase is a 2D infinite runner game developed in C++ using the SFML library. The project was created for lab final to apply Object-Oriented Programming concepts. The game features an auto-running bunny character that moves through an endless environment. Players can jump and slide across dynamically generated platforms while collecting carrots, coins, and power-ups, and avoiding obstacles.

## Features
- Infinite runner gameplay with automatic forward movement
- Dynamic platform generation
- Player animations (run, jump, slide, hurt)
- Collectible items with score and combo effects
- Collision detection and basic physics
- Parallax scrolling backgrounds
- Menu, pause, and game-over states
  
## Technologies Used
- Language: C++
- Library: SFML
- IDE: Visual Studio
  
## Object-Oriented Concepts used
The project follows an object-oriented structure where each game component is implemented as a separate class. Core OOP concepts used include:
- Encapsulation of player and game logic
- Inheritance through a base Entity system
- Polymorphism for collectible behavior
- Abstraction to manage complex systems
- State-based design for player actions and game flow
  
## Controls
- Space / Up Arrow – Jump
- Down Arrow – Slide
- Esc – Pause / Resume
